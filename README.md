# Tingjian - Global Radio — Support & Privacy

This public repository hosts only the support page and privacy policy for the iOS app **Tingjian - Global Radio** (`app.tingjian.ios`). It contains no proprietary app source code and no private contact details such as a personal phone number or email address.

本仓库仅用于公开托管 iOS 应用 **Tingjian - Global Radio**（`app.tingjian.ios`）的使用支持页和隐私政策页。不含应用私有源码，也不公开个人手机号或个人邮箱。

## Public URLs / 公开地址

- Support / 使用支持: https://spinodehong-web.github.io/tingjian-support/
- Privacy Policy / 隐私政策: https://spinodehong-web.github.io/tingjian-support/privacy.html

Feedback is welcome through [GitHub Issues](https://github.com/spinodehong-web/tingjian-support/issues) in this repository.

如需反馈，请使用本仓库的 [GitHub Issues](https://github.com/spinodehong-web/tingjian-support/issues)。
